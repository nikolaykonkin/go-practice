# concurrent-tasks

Консольная программа, которая запускает несколько горутин с I/O- и вычислительными задачами и показывает прогресс в реальном времени. Демонстрирует разницу между конкурентным и параллельным выполнением.

## Что показывает

- запуск нескольких горутин с `sync.WaitGroup`;
- I/O-задачи (со случайной задержкой) и вычислительные задачи (Fibonacci);
- передачу результатов через буферизированный канал;
- мониторинг прогресса в реальном времени через `time.NewTicker` и `select`;
- корректное закрытие канала и завершение монитора.

## Запуск

```bash
go run main.go
```
