# mutex-basics

Демонстрация синхронизации горутин через `sync.Mutex` и `sync.WaitGroup`: несколько горутин параллельно инкрементируют общий счетчик.

## Что показывает

- защиту разделяемой переменной через `sync.Mutex`;
- ожидание завершения всех горутин через `sync.WaitGroup`;
- корректный вызов `defer wg.Done()` для гарантии освобождения счетчика;
- отсутствие гонок данных при параллельном инкременте.

## Запуск

```bash
go run main.go
```

Проверка на гонки данных:

```bash
go run -race main.go
```

## Пример вывода

```
Итоговое значение счётчика: 10000
Ожидаемое значение: 10000
```
