# channels-worker-pool

Консольная программа, моделирующая обработку заказов интернет-магазина через worker pool. Демонстрирует работу с каналами в Go.

## Что показывает

- небуферизированный канал для передачи заказов между горутинами;
- паттерн Worker Pool: фиксированное число воркеров (3) читают из общего канала;
- закрытие канала как сигнал завершения для `for range`;
- синхронизацию без `sync.WaitGroup` — только через каналы;
- канал `done` для сбора сигналов о завершении каждого воркера.

## Запуск

```bash
go run main.go
```
