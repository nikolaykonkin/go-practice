# fan-in

Консольная программа-эмулятор системы мониторинга, которая собирает метрики от трех источников (CPU, Memory, Network) и объединяет их в единый поток. Демонстрирует паттерн Fan-in в Go.

## Что показывает

- паттерн Fan-in: слияние нескольких каналов в один;
- генераторы метрик, возвращающие `<-chan Metric` (только для чтения);
- корректное закрытие каналов через `defer close(ch)`;
- синхронизацию через `sync.WaitGroup`;
- закрытие выходного канала в отдельной горутине после `wg.Wait()`.

## Запуск

```bash
go run main.go
```

## Пример вывода

```
Запуск системы мониторинга
Источник: CPU, Значение: 45.67, Время: 15:30:15.123
Источник: Memory, Значение: 8192.34, Время: 15:30:15.456
Источник: Network, Значение: 567.89, Время: 15:30:15.789
...
Мониторинг завершён
```

Программа выводит ровно 15 метрик (5 от CPU + 5 от Memory + 5 от Network).
Порядок метрик недетерминирован — это особенность параллельной работы источников.
