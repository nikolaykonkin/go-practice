# employees-list

Консольная программа для фильтрации списка сотрудников по возрасту и минимальной зарплате. Демонстрирует структуры, срезы и интерфейсы в Go.

## Что показывает

- структуру `Employee` с полями разных типов;
- хранение списка сотрудников в срезе;
- интерфейс `Displayable` с методом `Display()` и его реализацию для `Employee`;
- фильтрацию по двум критериям одновременно;
- добавление нового элемента в срез.

## Запуск

```bash
go run main.go
```
