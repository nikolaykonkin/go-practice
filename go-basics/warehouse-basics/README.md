# warehouse-basics

Консольная программа для управления небольшим складом товаров. Демонстрирует основные конструкции языка Go.

## Что показывает

- разные способы объявления и инициализации переменных (`var`, `:=`, групповое `var (...)`);
- константы (`const`) для категорий и лимитов;
- разные числовые типы: `int8`, `int`, `uint`, `float32`, `complex64`;
- явное приведение типов (например, `int` → `float64` перед делением);
- работу со строками и рунами: разница между длиной в байтах и символах;
- функции с разными сигнатурами и возвращаемыми значениями.

## Запуск

```bash
go run main.go
```
