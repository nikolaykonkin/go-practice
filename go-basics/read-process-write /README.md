# read-process-write

Консольная программа, которая читает текст из файла, обрабатывает его и записывает результат в другой файл. Демонстрирует работу с функциями и обработку ошибок при работе с файлами.

## Что показывает

- чтение всего файла через `os.Open` и `io.ReadAll`;
- запись в файл через `os.Create` и `WriteString`;
- гарантированное закрытие файлов через `defer`;
- оборачивание ошибок с контекстом через `fmt.Errorf(... %w ...)`;
- передачу функции-обработчика как аргумента (higher-order function).

## Запуск

```bash
go run main.go
```

Программа читает `input.txt`, применяет к содержимому `strings.ToUpper`
и записывает результат в `output.txt`.

## Пример работы

**До — `input.txt`:**

```
Hello, Go!
Это тестовый файл для демонстрации чтения и записи.
```

**После — `output.txt`:**

```
HELLO, GO!
ЭТО ТЕСТОВЫЙ ФАЙЛ ДЛЯ ДЕМОНСТРАЦИИ ЧТЕНИЯ И ЗАПИСИ.
```

**Вывод в консоль:**

```
Файл успешно обработан и сохранён в output.txt
```

**Если файл не найден** — программа вернёт ошибку с контекстом:

```
Программа завершилась с ошибкой: открытие входного файла: open input.txt: no such file or directory
```
