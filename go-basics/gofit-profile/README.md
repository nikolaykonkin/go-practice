# gofit-profile

Консольное приложение, которое выводит профиль пользователя утилиты GoFit. Демонстрирует базовые типы данных Go: строку, целое число, вещественное число и логическое значение.

## Что показывает

- объявление константы `AppName` для названия программы;
- использование группового объявления `var (...)` для нескольких переменных;
- строковый, целочисленный, вещественный и логический типы данных;
- форматированный вывод через `fmt.Printf`.

## Запуск

```bash
go run main.go
```

## Пример вывода

```
Добро пожаловать в GoFit!
Профиль пользователя:
Имя: Иван
Возраст: 30 лет
Рост: 1.75 м
Подписан на рассылку: true
```
