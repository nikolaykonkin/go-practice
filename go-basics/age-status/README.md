# age-status

Консольная программа, которая 5 раз запрашивает у пользователя возраст и выводит статус: «Ребёнок», «Взрослый» или «Пенсионер». Демонстрирует условные конструкции и циклы в Go.

## Что показывает

- цикл `for` для повторяющихся операций;
- конструкцию `switch` без выражения (эквивалент цепочки `if/else if/else`);
- обработку пользовательского ввода через `fmt.Scan`;
- обработку отрицательных значений как ошибочного ввода.

## Запуск

```bash
go run main.go
```

## Пример работы

```
Введите возраст: 16
Ребёнок
Введите возраст: 30
Взрослый
Введите возраст: 70
Пенсионер
Введите возраст: -5
Ошибка: возраст не может быть отрицательным
Введите возраст: 65
Взрослый
```
