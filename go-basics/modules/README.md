# modules

Демонстрация системы модулей и работы с пакетами в Go: библиотека `mymath` и приложение `app`, которое ее использует через `replace` для локальной разработки.

## Что показывает

- создание Go-модуля через `go mod init`;
- подключение локального модуля через `replace` в `go.mod`;
- импорт функций из модуля в другом проекте;
- тесты для функций модуля.

## Про `replace`

Директива `replace example.com/mymath => ../mymath` в `app/go.mod` позволяет использовать **локальную** версию модуля вместо опубликованной. Это стандартный прием для разработки: пока модуль не опубликован, проект ссылается на локальную папку.

В продакшене `replace` убирается, а модуль подключается по URL:

```
require example.com/mymath v1.0.0
```

## Запуск

```bash
cd app
go run main.go
```

## Тесты модуля

```bash
cd mymath
go test ./...
```

## Пример вывода

```
7 + 5 = 12
7 * 5 = 35
```

## Структура

```
modules/
├── mymath/          — библиотека с функциями Add и Multiply
│   ├── go.mod
│   ├── math.go
│   └── math_test.go
└── app/             — приложение, использующее mymath
    ├── go.mod
    └── main.go
```
